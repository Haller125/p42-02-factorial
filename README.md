## Условие

Дано неотрицательное целое число n. Вычислите факториал n: n! = n * (n - 1) * (n - 2) * ... * 1. Факториал 0 по определению равен 1.

Факториал быстро растёт, поэтому метод возвращает long. Тип в заготовке не меняйте.

**Примеры**

```
Вход: n = 5
Выход: 120
Пояснение: 5! = 5 * 4 * 3 * 2 * 1 = 120

Вход: n = 4
Выход: 24
Пояснение: 4! = 4 * 3 * 2 * 1 = 24

Вход: n = 0
Выход: 1

Вход: n = 1
Выход: 1
```

## Как выполнить

1. Один человек из команды нажимает **Fork** (вверху справа) и добавляет напарника: Settings → Collaborators → Add people.
2. Оба клонируют форк и открывают его в VS Code:
   ```
   git clone https://github.com/<ваш-ник>/p42-02-factorial
   cd p42-02-factorial
   code .
   ```
3. Впишите в таблицу «Команда» выше свои ФИО и ники GitHub.
4. В `Program.cs` напишите решение внутри метода `Factorial` (вместо строки `return 0;`). Метод `Main` и `Check` не меняйте.
5. Запустите:
   ```
   dotnet run
   ```
   Все проверки должны показать `OK`.
6. Сохраните работу в GitHub (коммитят оба участника):
   ```
   git add .
   git commit -m "Решение"
   git push
   ```
